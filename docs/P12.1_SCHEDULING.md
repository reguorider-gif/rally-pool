# P12.1 调度策略 / 部署策略说明

## 概述

AI Judge 预测池采用 **双层调度策略**：

| 调度器 | 角色 | 用途 |
|---|---|---|
| **GitHub Actions** | 主调度器 | 执行 pipeline、生成文件、commit/push、可选部署 Vercel |
| **Vercel Cron** | 轻量探针 | 定时读取最新 pipeline 状态，确认 API 可用，不写文件 |

## 1. GitHub Actions（主调度器）

### 文件位置

`.github/workflows/daily-pool-pipeline.yml`

### 触发方式

1. **定时触发（schedule）**：每天 UTC 09:15 → 北京时间 17:15
2. **手动触发（workflow_dispatch）**：
   - 打开 GitHub 仓库 → Actions → "AI Judge Daily Pool Pipeline" → Run workflow
   - 可指定 `date`、`round`、`deploy`

### 执行流程

```
1. Checkout 代码
2. Python 3.11 环境
3. py_compile 预检
4. validate_pool_schemas.py + check_pool_data_health.py
5. run_daily_pool_pipeline.py --skip-browser --continue-on-warning
6. 再次 validate + health check
7. 显示 pipeline Markdown 摘要
8. Commit 生成的 data/pool 文件
9. Push 到仓库
10. （可选）Vercel 部署
```

### 需要配置的 GitHub Secrets

| Secret | 必需 | 说明 |
|---|---|---|
| `VERCEL_TOKEN` | 仅 deploy=true | Vercel 个人 token |
| `VERCEL_ORG_ID` | 仅 deploy=true | Vercel 组织 ID |
| `VERCEL_PROJECT_ID` | 仅 deploy=true | Vercel 项目 ID |

### 可选 Secrets

| Secret | 说明 |
|---|---|
| `THE_ODDS_API_KEY` | 体育赔率 API key，当前默认用 manual_stub |

### 当前限制

- `--skip-browser` 默认开启（浏览器采集不稳定）
- `deploy=false` 默认不部署（避免未配 secrets 时报错）
- run-6 当前状态 `waiting_for_manual_ingest`
- pipeline 有 warning 不代表失败

---

## 2. Vercel Cron（轻量探针）

### 文件位置

`vercel.json` → `crons` 配置

### API 端点

`GET /api/cron/pipeline-status`

### 行为

- 读取最新 pipeline run 状态
- 读取最新 daily report 状态
- 返回 JSON 状态摘要
- **不写文件、不触发 pipeline、不部署**
- 即使无 pipeline 也返回 `ok=true` + warning

### 调度

每天 UTC 09:30 → 北京时间 17:30（比 GitHub Actions 晚 15 分钟）

---

## 3. 为什么不用 Vercel Cron 直接写 data 文件

1. 数据文件存放在 repo 内（`data/pool/`）
2. 需要 commit → push → redeploy 才能记录为可审计的历史
3. Vercel Serverless Function 没有持久文件系统，不适合做 repo 写入
4. GitHub Actions 有完整的 CI/CD 环境，适合执行脚本、提交变更

---

## 4. 调度时间线（北京时间）

| 时间 | 事件 | 调度器 |
|---|---|---|
| 17:15 | Pipeline 执行 | GitHub Actions |
| 17:15-17:20 | Commit + Push 生成文件 | GitHub Actions |
| 17:20 | （可选）Vercel 部署 | GitHub Actions |
| 17:30 | 状态探针确认 | Vercel Cron |

---

## 5. 手动触发示例

### GitHub Actions

```
Actions → AI Judge Daily Pool Pipeline → Run workflow
  date: 2026-06-03
  round: run-6
  deploy: false
```

### 本地 CLI

```bash
python3 ops/run_daily_pool_pipeline.py --date 2026-06-03 --round run-6 --skip-browser
```
